## Featured Projects

### SU Career Portal

A centralized web-based career opportunities platform designed to improve how students and alumni discover and manage internships, jobs, and graduate opportunities.

The platform supports opportunity discovery, filtering, saving, applications, and application progress tracking, with dedicated dashboards and role-based access for Students, Employers, and Career Development Services administrators. It also includes document uploads, notifications, employer applicant management, and job-posting approval workflows.

**Tech:** <kbd>React</kbd> <kbd>Firebase Authentication</kbd> <kbd>Cloud Firestore</kbd> <kbd>Cloud Storage</kbd> <kbd>Firestore Security Rules</kbd>

---

### SU Community Portal

A centralized web portal developed to improve communication and access to information within the Strathmore community.

Led a team of three while developing the frontend with React and coordinating backend integration to deliver the platform's core functionality.

**Tech:** <kbd>React</kbd> <kbd>JavaScript</kbd>

### E-Tiko

An e-ticketing web application developed to support event, ticket, booking, and user management through a centralized platform.

Developed the Spring Boot backend, implementing REST APIs, booking workflows, digital ticket processing, role-based access, and core event and ticket operations.

**Tech:** <kbd>Java</kbd> <kbd>Spring Boot</kbd> <kbd>REST APIs</kbd>

---

### Gym Management System

A scalable gym management system built to streamline bookings, scheduling, and user management.

Implemented booking and scheduling modules with time-slot conflict detection, RESTful APIs, and robust validation, supporting concurrent group bookings and efficient system operations.

**Tech:** <kbd>Java</kbd> <kbd>Spring Boot</kbd> <kbd>REST APIs</kbd>
